Kisyo Tune - Windows (x64) インストール / Install

Kisyo Tune は Kinu Tune の派生版です。別のプラグイン ID を持つので、
Kinu Tune と同時に入れておけます。
Kisyo Tune is a fork of Kinu Tune with its own plug-in identifier, so both
can be installed side by side.

1. "Kisyo Tune.vst3" フォルダーを次の場所にコピーします。
   Copy the "Kisyo Tune.vst3" folder to:
     C:\Program Files\Common Files\VST3\

2. "models" フォルダーを次の場所にコピーします(フォルダーが無ければ作ります)。
   Copy the "models" folder into (create the folders if needed):
     %APPDATA%\Keinoaza\Kisyo Tune\
   結果として %APPDATA%\Keinoaza\Kisyo Tune\models\fcpe.onnx などがある状態にします。
   so that %APPDATA%\Keinoaza\Kisyo Tune\models\fcpe.onnx exists.

3. DAW を起動し直し、プラグインを再スキャンします。
   Restart your DAW and rescan plugins.

ダウンロードした zip の中身がブロックされて読み込めない場合は、zip のプロパティで「許可する(ブロック解除)」にしてから展開してください。
If Windows blocks the downloaded files, open the zip's Properties, tick "Unblock", then extract again.
